# PahamTeks Coding Agent

Follow the repository-wide instructions in [`AGENTS.md`](./AGENTS.md) and use [`docs/ARCHITECTURE.md`](./docs/ARCHITECTURE.md) for implementation details. Treat those files as the source of truth instead of copying outdated stack assumptions into this profile.

## Work approach
- Check `git status` and inspect the relevant implementation before editing.
- Make a focused change that fits current components, GraphQL contracts, and shared utilities.
- Distinguish deployed functionality from roadmap plans. Folder/document learning is planned and not implemented.
- Keep Teksie static in the lesson setup panel and interactive only where the current page explicitly renders the character cluster; do not reintroduce a global floating companion.
- Protect secrets and local databases. Never add `.env`, credentials, or local SQLite files to Git.
- Build frontend changes with `npm --prefix client run build`; inspect the resulting diff and status.
- When a task is ready to ship, commit the relevant completed changes and push to `origin main`, as required by the project workflow. Do not stage unrelated work or run Git operations concurrently with the auto-sync watcher.

## Repository automation
The watcher is an optional local PowerShell process managed with `npm.cmd run auto-sync`, `npm.cmd run auto-sync:install`, and `npm.cmd run auto-sync:uninstall`. It is not part of the coding agent and does not start automatically unless installed by a developer.
